# Quiz Mania 🎮

Jogo de perguntas e respostas no terminal, feito em C como trabalho final de **Algoritmos e Programação de Computadores I** (IESB). Foi um dos meus primeiros projetos de programação.

## Funcionalidades
- Temas: **Automobilismo** e **Filmes e séries**
- Pontuação por jogador
- **Ranking** com os resultados da partida
- Interface colorida no terminal (códigos ANSI)

## Como rodar
```bash
gcc trabalho.c -o quiz
./quiz
```

## Arquivos
| Arquivo | Conteúdo |
|---|---|
| `trabalho.c` | Versão final do jogo |
| `quizgame.c`, `quiz1` | Versões anteriores / rascunhos |
| `main.c`, `teste2.c` | Testes durante o desenvolvimento |
